# 妙响自动化控制台

这是一个本地运行的网页控制台，用确定性 Python + Playwright 脚本处理妙响音乐生成、导出和下载。运行时不接 AI，不做人机轨迹伪装，也不做验证码或平台检测绕过。

## 启动

双击：

```text
启动控制台.bat
```

或手动运行：

```powershell
cd /d F:\音乐\aimusic\.worktrees\console-v2
.\.venv\Scripts\python -m backend.main
```

浏览器会打开：

```text
http://127.0.0.1:8787
```

首次启动脚本会自动创建 `.venv` 并安装依赖。

## 第一次使用

1. 在左侧点击「新建」。
2. 填写账号名称、Chrome 用户目录、调试端口、歌词根目录、成品根目录、下载目录。
3. 保存账号。
4. 点击「打开 Chrome 登录」。
5. 在弹出的 Chrome 里登录妙响账号。
6. 登录完成后点击「关闭登录浏览器」。
7. 把歌词 Markdown 放到项目根目录的当天日期文件夹里。例如账号里填写 `F:\音乐\歌词\白日逐梦`，当天是 2026-09-17，则歌词放在：

```text
F:\音乐\歌词\白日逐梦\2026-09-17\01_歌曲.md
```

8. 回到控制台点击「刷新」，确认歌词解析有效。
9. 勾选歌曲，点击「开始处理」。

每个账号使用独立 Chrome 用户数据目录，不同账号不要共用同一个目录和端口。

## 歌词格式

```markdown
# 歌名：《歌曲名》

## 歌词
《歌曲名》
歌词正文，长度必须大于 100 字符
[End]

## 歌曲风格
一行式风格描述，长度必须大于 50 字符
```

解析失败的歌曲不会进入浏览器流程，避免浪费生成次数。

## 运行控制

- `开始处理`：按勾选顺序串行处理。
- `暂停`：当前步骤完成后暂停。
- `继续`：从暂停处继续。
- `停止`：不再开始新步骤，保存状态并释放 Chrome。
- `忽略断点全部重跑`：不复用当天已成功记录。

生成上限提示会立即停止整个任务，不会重试。

## 输出与调试

成品默认归档到你配置的：

```text
成品根目录/当天日期/歌曲名.mp3
```

同名文件会自动追加 `-2`、`-3`，不会覆盖。

## 批量生成

账号可以设置「批量生成数量」，当前最大为 2。脚本会连续提交两首不同歌词，等待平台返回结果后逐张打开详情，用歌词内容判断每张卡片属于哪次提交。每个歌词若有多个版本，默认导出资产列表中最新的第一个匹配版本；另一个版本只用于校验，不导出。

如果两首提交后平台一首都没有生成，脚本会记录生成失败并按重试策略重试。如果只有其中一首没有匹配结果，只重试缺失的那首；已经生成成功的版本不会被重复生成。

## 控制台导航

控制台使用左侧导航：

```text
任务管理
妙响账号
运行日志
系统设置
AI 作词（待接入）
```

任务管理包含三个阶段：

```text
AI 作词（待接入）
生成 / 导出 / 下载
上传作品（待接入）
```

当前已开放生成阶段。上传批次会实时读取当前账号当天成品目录中的 MP3，显示文件、大小、批次上限和授权真实姓名。发布全曲自动化接入后，会在同一任务管理页启动。

## 发布全曲

发布全曲按账号批量执行，单批最多 10 首。上传必须等待当前账号本批次所有可成功下载的 MP3 完成后才开始。如果平台生成次数达到上限，则停止新生成，只上传已经下载成功的部分。

发布流程要求：

1. 每首歌选择 AI 创作为“是”，AI 工具选择“其他”并填写“妙响”。
2. 音乐类型选择“原创”。
3. 上传对应 MP3，填写歌曲标题和纯歌词文本。
4. 10 首添加完成后填写专辑名称。
5. 使用智能封面，等待“使用封面”可点击。
6. 每首歌为制作人、词作者、曲作者点击“添加自己”。
7. 词作者和曲作者真实姓名填写账号配置中的授权真实姓名，默认“龙英”。
8. 艺人信息补充选择“无主页链接”。
9. 签署合同并发送手机验证码。
10. 用户输入验证码后完成发布。

日志目录：项目内 `logs/`  
截图目录：项目内 `screenshots/`  
配置和断点：项目内 `data/`

页面操作异常会保存全页截图，日志会显示当前步骤、歌曲、错误和截图路径。

## 安全边界

- 本控制台只监听 `127.0.0.1`。
- 不提供远程访问。
- 不保存平台密码。
- 不做检测规避。
- 单账号串行执行，避免多任务同时操作同一个浏览器配置。

## 常见问题

**为什么打开登录浏览器后不能直接开始任务？**

需要先关闭登录浏览器释放用户目录锁。点击「开始处理」时程序也会自动关闭登录浏览器。

**中断后再开会重复生成吗？**

当天同一账号下已标记成功的歌词会默认跳过。需要重跑时勾选「忽略断点全部重跑」。

**Chrome 没启动怎么办？**

确认本机安装了 Chrome 或 Edge，且账号的调试端口没有冲突。程序默认搜索常见 Chrome/Edge 安装路径。

**任务卡住怎么办？**

点击「停止」。所有等待都有上限，当前操作会尽快收尾并保存截图与状态。

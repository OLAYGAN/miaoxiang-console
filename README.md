# 妙响自动化控制台

本机运行的妙响音乐自动化控制台。程序通过 FastAPI 提供网页界面，通过 Playwright 连接独立的 Chrome/Edge 用户目录，完成 AI 作词、音乐生成、成品导出下载、批量上传和发布流程。

控制台只监听 `127.0.0.1`，账号密码不会写入项目，平台验证码由用户在 Chrome 中手动输入。

## 主要功能

### 妙响账号

- 每个账号绑定独立的歌词目录、成品目录、下载目录和 Chrome 用户目录。
- 自动检测并分配可用的 Chrome 调试端口。
- 新账号只需要选择账号总文件夹，系统按约定创建分类目录和 `Chrome\账号名` 用户目录。
- 支持账号复制。复制账号时会复制对应 Chrome 用户目录并分配新端口，不会让两个账号共用同一浏览器进程。
- 删除账号时可同时删除对应的 Chrome 用户目录；歌词和音乐成品不会被删除。
- 修改已有账号名称不会自动改动绑定的歌词、成品、下载和 Chrome 目录，避免丢失原登录状态。

### AI 作词

- 每个妙响账号可以保存多个作词模板。
- 模板包含歌曲风格、歌词格调、多选主题、生成数量和绑定账号。
- 生成位置跟随绑定账号的歌词根目录和当天日期。
- 通用规则提示词可以修改，并会与模板一起发送给 OpenAI 兼容接口。
- 保存模板或通用规则时会自动收起编辑窗口。
- 支持流式显示 API 连接、已接收字符、推理摘要和已发现的歌名。
- AI 返回结果会校验 JSON、歌曲数量、歌名重复、歌词长度和曲风长度。

### 生成、导出和下载

- 从“歌词根目录\当天日期”读取 Markdown 歌词。
- 生成模型在任务参数中选择，默认“自动”；选择结果保存在浏览器本地，刷新后保持。
- `Sway v5.5` 额外支持人声选择，默认“不选择”；选择具体人声后才会操作平台虚拟歌手控件。
- 批量提交后按生成详情中的歌名与歌词文件歌名匹配，不依赖平台随机标题。
- 只下载已导出的匹配版本；同名文件使用临时文件和原子替换，避免下载中断破坏旧文件。
- 平台提示“无法根据描述生成，请修改”时跳过当前歌曲，继续处理后续歌曲。
- 已完成歌曲默认跳过，可勾选“全部重跑”重新处理。

### 上传作品

- 从当天成品目录批量读取 MP3。
- 支持批量上传，上传完成后再填写专辑信息。
- 自动剔除平台标记为不合格的曲目，不删除本地音乐文件。
- 支持“发布全曲”“停止上传”和“再次生成发布”。
- “再次生成发布”会重新生成待发布歌曲，下载成功后覆盖原同名文件并重新上传。
- 真实姓名读取账号设置，不在上传页面重复填写。
- 手机验证码阶段会保留浏览器窗口，只有检测到发布成功页面后才结束。

### 完整流水线

- 可选择单个账号执行，也可勾选多个账号组成全局阶段队列。
- 多账号按全局阶段执行：所有账号 AI 作词 -> 所有账号生成下载 -> 所有账号上传发布 -> 运行报告。
- 完整流水线中的生成失败最多重试 2 次，即单首歌最多 3 次生成尝试。
- 每个账号保存独立快照，界面显示全局阶段进度和每个账号的作词、生成、上传完成度。
- 支持所有账号生成完成后统一暂停确认、停止队列和继续上传。
- 单首歌曲或单个账号失败不会阻塞其它歌曲和账号。

## 技术架构

- 后端：Python 3.11、FastAPI、Uvicorn、Pydantic。
- 浏览器自动化：Playwright 通过 Chrome DevTools Protocol 连接本机 Chrome/Edge。
- 前端：原生 HTML、CSS、JavaScript，无前端构建步骤。
- 持久化：`data/` 下的原子写入 JSON 文件。
- 实时状态：FastAPI WebSocket 推送任务、日志和流水线快照。

详细模块划分、数据流和扩展方式见 [代码说明](docs/代码说明.md)。

## 快速启动

要求：

- Windows 10/11
- Python 3.11 或更高版本
- Google Chrome 或 Microsoft Edge

双击：

```text
启动控制台.bat
```

脚本会在首次运行时创建 `.venv`、安装项目依赖并打开：

```text
http://127.0.0.1:8787
```

手动启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
.\.venv\Scripts\python -m backend.main
```

如果端口被占用，可以指定其它端口：

```powershell
.\.venv\Scripts\python -m backend.main --port 8788
```

## 目录和日期规则

账号保存的是根目录。实际读写时会自动追加当天日期：

```text
歌词根目录\YYYY-MM-DD\
成品根目录\YYYY-MM-DD\
下载根目录\YYYY-MM-DD\
```

例如今天为 `2026-09-24`，歌词根目录是 `F:\音乐\歌词\白日逐梦`，程序会读取：

```text
F:\音乐\歌词\白日逐梦\2026-09-24\
```

当天目录不存在时会自动创建。Chrome 用户目录使用：

```text
账号总文件夹\Chrome\账号名
```

## 歌词格式

```markdown
# 歌名：《歌曲名》

## 歌词
歌名：《歌曲名》

[Verse 1][English performance and arrangement direction]
中文歌词
(performance cue)
[End]

## 歌曲风格
[genre and mood][instruments, vocals, duration and negative constraints]
BPM 82 | Key D major | Total 24 bars ~84 seconds
Vocal roles: ...
```

控制台兼容旧格式和 AI 作词输出的结构指令格式。解析失败的歌词不会进入浏览器流程。

发布时必须复制整个 `MiaoxiangConsole` 文件夹，不能只复制 exe。详细说明见 [打包与部署说明](打包与部署说明.md)。

## 数据和运行边界

- `data/`、`logs/`、`screenshots/` 均位于程序可写目录。
- `data/` 包含账号配置、AI API 配置、歌词模板和任务断点，不应提交到公开仓库。
- Chrome 用户目录由账号单独管理，不同账号不能共用同一个目录和调试端口。
- 程序不做平台检测绕过，不代替用户完成手机验证码。
- 页面等待均有超时，异常时会保存日志和全页截图，便于定位选择器变化。
